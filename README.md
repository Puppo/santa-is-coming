# Santa Is Coming — Villaggio di Babbo Natale 3D

Interactive 3D Santa's Village diorama built with **React 19**, **React Three Fiber**, **Three.js**, **Drei**, and **TypeScript**, designed for desktop, tablet, and mobile browsers with bilingual **IT / EN** controls.

## Features

- **Living 3D Diorama**: Textured snow terrain, frozen skating pond, cobblestone paths, aurora borealis sky, volumetric snowfall, warm cabin windows, and adaptive bloom.
- **Interactive Zones**: One-tap camera flight across the Village Panorama, Great Tree Plaza (with animated miniature toy train), Elves' Toy Workshop, Reindeer Paddock & Sleigh (including a 3D Sleigh Test Flight!), and Santa's Cozy Chalet with North Pole mailbox.
- **Animated Characters**: Gift-carrying & tinkering elves, strolling Santa, skeletal-animated reindeer (`Stag.glb`), and periodic surprise visits from **Il Guastafeste (The Holiday Grump)** that kids and adults can catch.
- **Christmas Jukebox & Party Mode**: 5 real Public Domain / CC Christmas recordings paired with real-time Web Audio frequency analysis so village fairy lights and characters groove to the music.

## Local Development

```bash
pnpm install
pnpm dev
```

## Build & Tests

```bash
pnpm test -- --run
pnpm run build
```
